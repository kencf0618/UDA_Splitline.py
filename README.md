Theoretical basis: ReCom MCMC, GerryChain, Polsby-Popper.
Data sources: county-adjacency package, 2020 Census state totals.
The United Districts of America (UDA) concept itself is a political and mathematical argument.
Known limitations: synthetic county populations, abstract map rendering, undersampled chain, innate absurdity.
This is a proof of concept requiring real TIGER data and serious compute for production use (which'll never happen).
