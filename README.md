It also serves pedagogical purposes if you're twisted enough.

Theoretical basis: ReCom MCMC, GerryChain, Polsby-Popper, splitline.

Data sources: county-adjacency package, 2020 Census state totals, TIGER, etc. 

Known limitations: synthetic county populations, abstract map rendering, undersampled chain, and innate absurdity
(which in and of itself might be a feature, to be honest).

This is a proof of concept requiring real data and serious compute for production use (which'll never happen).
